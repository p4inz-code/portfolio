## 2. STANDING WORKFLOW RULES (non-negotiable)

Applies to every task. Violating these has cost real time.

- **Ask before big changes.** Plan+demo before touching real files unless user has said GO in the current message.
- **"Plan mode"** = investigation + proposal only. **"GO"** = execute signal.
- **MAJOR.MINOR.PATCH** semver on every commit. `SITE.currentVersion` in `src/data/site.ts` + `package.json` version + `src/data/changelog.ts` entry must all bump together.
- **Yap less, work more.** Responses concise. No filler.
- **Brutal honesty over flattery.** Retract findings the moment verification disproves them.
- **Never fabricate project facts** — versions, dates, feature status. Verify against `data/projects.ts` + real README + repo before asserting. Flag contradictions, don't guess.
- **Content-accurate over content-marketed** — this is a real editorial principle on the site now (`/editorial`).
- **Batch commits are OK** — 3-5 small fixes per version-bump is the working rhythm. Full changelog entry every bump.
- **Never oversell.** Status labels must reflect real state (Mission OS = "Active Development · Pre-release · internal testing", never "production-ready").
- **Never merge / push / deploy to `main` without explicit user OK** — except when user is in an active "keep pushing" burst and the pattern has been established for that session.
- **The site is live at atharvapatil.tech since 2026-08-10.** Every merge to `main` deploys via Cloudflare Pages in ~90 seconds. This is production now.

### Parchment grain (light theme only)

Two-layer `feTurbulence` SVG on `body::before` + `body::after` with `mix-blend-mode: multiply`. Turns the flat cream into cotton-paper texture. Hidden on the Mission OS demo route.

### Motion

- Curve: `--ease-out: cubic-bezier(0.16, 0.8, 0.24, 1)`
- Durations: 150 / 300 / 500 ms
- `prefers-reduced-motion: reduce` globally sets animation/transition-duration to 0.001ms in `tokens.css`
- Scroll-linked animations use CSS `animation-timeline: view()` and `scroll()` — zero JS
- On mobile (<760px), the FeaturedShowcase merry-go-round rotation is replaced with a simpler opacity + translate reveal (v5.16.0 fix — 3D rotation on phones was disorienting)
